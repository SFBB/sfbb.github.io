# sfbb.github.io

基于 **Astro + Tailwind CSS** 构建的现代交互式工程师主页与项目展示作品集（参考经典 Developer Portfolio 架构），专为展示工作经历、精选项目与技术栈而设计。

访问地址：[https://sfbb.github.io/](https://sfbb.github.io/)

## 📝 源码管理

- 项目源码保存在 **`main`** 分支。平时修改内容后正常推送源码：

  ```bash
  git add .
  git commit -m "some comment"
  git push origin main
  ```

- 网站artifacts在**gh-pages**分支。部署网站时只需运行 `./deploy.sh`，源码和编译产物互不干扰，干净整洁。
